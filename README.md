# Пароли — менеджер паролей PWA

Работает на Mac, iPhone, iPad (и на любом устройстве с современным браузером).
Без интернета, без сервера, без сторонних библиотек.

## Как устроено

- Все записи хранятся **одним зашифрованным файлом**. Без мастер-пароля не видно даже названий сайтов.
- Шифрование: AES-256-GCM. Ключ получается из мастер-пароля через PBKDF2-SHA256 с 600 000 повторами.
- Если в файле изменить хотя бы один байт, программа это обнаружит и откажется его открывать.
- Мастер-пароль нигде не хранится. **Если его забыть, данные восстановить нельзя.**
- Через 3 минуты бездействия и при сворачивании хранилище блокируется.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html`, `style.css` | Интерфейс |
| `app.js` | Логика: поиск, добавление, импорт и экспорт, автоблокировка |
| `crypto.js` | Шифрование |
| `sw.js` | Работа без интернета (кэш) |
| `manifest.json`, `icon-*.png` | Установка на экран «Домой» |
| `server.py` | Локальный сервер для Mac: пишет файл хранилища на диск |
| `install.sh`, `uninstall.sh` | Установка и удаление на Mac |
| `tools/test-crypto.mjs` | Тесты шифрования: `node tools/test-crypto.mjs` |
| `tools/make_icons.py` | Генератор иконок |

## Mac

**Установка:** `./install.sh`. Скрипт копирует программу в `~/Library/Application Support/pswd/`
и включает автозапуск локального сервера (`server.py`) по адресу http://localhost:8765. Сервер доступен только с этого компьютера.

**Где пароли:** `~/Documents/Пароли/pswd-vault.txt` (зашифрован). Файл обновляется при каждом изменении.
Рядом лежит `pswd-vault.bak.txt` — предыдущая версия.

**В Dock:** откройте http://localhost:8765 в Safari → «Файл → Добавить в Dock».

**После изменения кода:** снова запустите `./install.sh`.

**Удаление:** `./uninstall.sh`. Файл с паролями при этом не удаляется.

## Установка на iPhone и iPad

Браузер даёт доступ к шифрованию только по **https://**, поэтому файлы нужно где-то разместить.
Проще и бесплатно это сделать через GitHub Pages. Публикуется только код программы, ваши пароли остаются на устройстве.
Затем откройте адрес в Safari → «Поделиться» → «На экран Домой».

## Синхронизация между устройствами

Каждое устройство хранит свою копию. Чтобы перенести данные:
1. «Файл и настройки» → «Сохранить файл хранилища». Файл `pswd-vault.txt` зашифрован, его можно положить в iCloud Drive.
2. На другом устройстве: «Импортировать файл» и ввести мастер-пароль.

Совет: время от времени делайте такую копию. Если удалить приложение с экрана «Домой», его данные пропадут.

## После изменения кода

Увеличьте номер версии `CACHE` в `sw.js`, иначе устройства продолжат открывать старую версию.
